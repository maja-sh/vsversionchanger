# VSVersionChanger

back in another life when i was in HS, we had two computer labs. the labs
had different Visual Studio versions. this caused the unfortunate problem
that projects created in the newer version to be incompatible with the
older version. the workaround for this was to move the project files into
a new project created in the newer version.

naturally, this started getting frustrating. this is how one of my favorite
scripts was born. it is as janky as it was useful.

this is published purely as an archeological find on a 15 year old hdd that
my dad silently held onto for a decade.

the only changes to the original code is the docblock, changing the name and
the license from MIT to 0BSD. not that anyone in their right mind would use
this anyway.
